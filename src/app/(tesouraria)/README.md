# (tesouraria) — painel da igreja (T-01 a T-06 e P-01 a P-04)

Pensado para a versão web. Telas do tesoureiro (fila de conferência, confirmar,
divergência, lançar em nome do membro, convites, relatório) e, numa subpasta própria,
as telas exclusivas do Pastor de Governo (P-01 a P-04). O layout do grupo bloqueia
quem não tem o perfil certo, mas a proteção de verdade dos dados é a RLS do banco.
